# 🗂️ Catálogo de Skills (Instrucciones de Agente)

Este repositorio contiene un ecosistema de **94 skills** diseñadas para guiar el comportamiento y las decisiones del agente de IA. Cada una de ellas es una carpeta autocontenida que incluye un archivo `SKILL.md` con reglas, patrones y flujos de trabajo específicos.

---

## 💡 ¿Cómo funcionan y cómo se activan?

Las skills **no requieren comandos manuales** (como `/comando`). Se activan **automáticamente** por el contexto de la conversación cuando el tema tratado coincide con su descripción y sus frases de disparo (*trigger phrases*).

*   ⚡ **Activación optimizada:** Skills auditadas para asegurar su correcto disparo automático por contexto de conversación.
*   🔧 **Invocación manual:** Skills configuradas deliberadamente con `disable-model-invocation: true` para ejecutarse únicamente bajo orden explícita debido a su impacto externo.

### 🎨 Diseño, UI/UX y Animación

| Skill | ¿Qué hace y cuándo se activa? |
| :--- | :--- |
| [**accessibility**](./accessibility/SKILL.md) | Diseña, implementa y audita productos digitales inclusivos utilizando los estándares WCAG 2.2 Nivel AA. Se activa para generar etiquetas semánticas ARIA en web y propiedades de accesibilidad tanto en plataformas web como nativas (iOS/Android). |
| [**animation-vocabulary**](./animation-vocabulary/SKILL.md) | Glosario de búsqueda inversa que traduce descripciones vagas de animaciones o efectos de movimiento en su término técnico exacto (ej. "lo que rebota al abrir un menú flotante" → *Pop in*; "el rebote elástico de scroll en iOS" → *Rubber-banding*). Se activa cuando el usuario pregunta "¿cómo se llama cuando...?" o describe un efecto de movimiento sin saber el nombre técnico y quiere la palabra exacta para pedírsela a una IA o a un diseñador. Sirve para nombrar el efecto, no para diseñarlo o codificarlo. |
| [**design-system**](./design-system/SKILL.md) | Se activa para generar o auditar sistemas de diseño, verificar la consistencia visual y revisar Pull Requests (PRs) que afecten a los estilos. |
| [**elegant-web-ui**](./elegant-web-ui/SKILL.md) | Diseña y construye interfaces web hermosas, modernas y de aspecto premium. Se activa cuando el usuario pide que una web, landing page, blog, panel de control o componente se vea "más bonito", "más elegante", "más profesional", "menos hecho por IA", o cuando pide mejorar/rediseñar una UI, elegir fuentes/colores o pulir la distribución (layout), espaciado y microinteracciones. Proporciona un sistema de diseño definido, patrones de componentes y una lista de control de calidad para lograr resultados sofisticados y de alta gama (funciona excelente con Astro/React/Tailwind, pero es independiente del framework). |
| [**emil-design-eng**](./emil-design-eng/SKILL.md) ⚡ | Incorpora la filosofía de Emil Kowalski sobre el pulido de interfaces, diseño de componentes, decisiones de animación y detalles invisibles que hacen que el software se sienta excelente. Se activa al pulir la UI, elegir o diseñar una animación/transición, o al revisar la calidad artesanal de los componentes e interacciones. |
| [**frontend-a11y**](./frontend-a11y/SKILL.md) | Patrones de accesibilidad para React y Next.js: HTML semántico, atributos ARIA, etiquetado de formularios, navegación por teclado, gestión de foco y soporte para lectores de pantalla. Se activa al construir cualquier componente de interfaz interactivo o formulario. |
| [**frontend-design**](./frontend-design/SKILL.md) | Guía para crear un diseño visual distintivo e intencionado al construir nuevas interfaces o rediseñar las existentes. Se activa para dar dirección estética, emparejar tipografías, maquetar layouts y tomar decisiones de diseño que no parezcan plantillas genéricas o valores por defecto generados por IA. Utilizar cuando se pida diseñar una página, elegir una dirección visual, hacer que un sitio web se sienta único/premium o evaluar si un diseño se ve genérico. |
| [**frontend-design-direction**](./frontend-design-direction/SKILL.md) | Define una dirección de diseño frontend específica para el trabajo de UI en producción. Se activa al construir o mejorar sitios web, dashboards, aplicaciones, componentes, landing pages, herramientas visuales o cualquier UI web que requiera un criterio de diseño más fuerte y específico del producto. |
| [**make-interfaces-feel-better**](./make-interfaces-feel-better/SKILL.md) | Aplica detalles prácticos de ingeniería de diseño que hacen que las interfaces se sientan pulidas y fluidas. Se activa al revisar o mejorar el espaciado, tipografía, bordes, sombras, movimiento (motion), áreas de clic, iconos, ajuste de texto y estados de interacción. |
| [**review-animations**](./review-animations/SKILL.md) ⚡ | Revisa el código de animación y movimiento bajo el estándar de alta calidad técnica (craft) derivado de la filosofía de ingeniería de diseño de Emil Kowalski. Por defecto es exigente y tiende a señalar problemas. Se activa cuando el usuario añade o cambia animaciones CSS/JS, transiciones o código de movimiento y quiere evaluarlos profesionalmente. |
| [**taste**](./taste/SKILL.md) | Capa de dirección creativa ("gusto/criterio") para videos musicales y ediciones en formato corto de la familia visual *angelcore* / *cloud-trance* / *hyperpop*. Define un vocabulario estético, un sistema de estado de ánimo + color + luz, y una edición sincronizada con el ritmo de la música. Encadena habilidades de video (edición de video, generación con fal.ai, creación con remotion, etc.) en un pipeline de producción coordinado. Se activa cuando el trabajo requiere que el video se sienta intencionado (no solo que funcione), al crear videos musicales, edits/fancams, reels guiados por moodboards o al elegir una dirección visual coherente para metraje de apoyo (b-roll) generado por IA. |
| [**web-design-guidelines**](./web-design-guidelines/SKILL.md) | Revisa el código de la interfaz para cumplir con las Web Interface Guidelines (Directrices de Interfaz Web). Se activa al pedir "revisar mi UI", "verificar accesibilidad", "auditar diseño", "revisar UX", "hacer el sitio más atractivo/profesional" o "comprobar el sitio frente a buenas prácticas". Lee las guías de Vercel y analiza los archivos indicados, reportando hallazgos concretos en formato archivo:línea. |

### 🔍 SEO y Visibilidad

Para auditorías de SEO tradicional, ver `seo-audit`. Para datos estructurados, ver `schema`. |
| [**programmatic-seo**](./programmatic-seo/SKILL.md) | Se activa cuando el usuario quiere crear páginas orientadas a SEO a gran escala mediante plantillas y datos estructurados (SEO Programático / pSEO). Cubre términos como páginas por lote, directorios, páginas locales ([palabra clave] + [ciudad]), comparativas y generación masiva de landing pages. Para auditar problemas existentes de SEO, ver `seo-audit`. Para planificación de estrategia de contenidos, ver `content-strategy`. |
| [**schema**](./schema/SKILL.md) | Se activa cuando el usuario quiere añadir, corregir u optimizar el marcado de esquemas (Schema.org) y datos estructurados (JSON-LD) en su sitio. Afecta a rich snippets, resultados enriquecidos de Google, esquemas de FAQ, productos, reseñas y migas de pan (breadcrumbs). Para temas generales de SEO, ver `seo-audit`. Para optimización en búsquedas de IA, ver `ai-seo`. |
| [**seo**](./seo/SKILL.md) | Audita, planifica e implementa mejoras generales de SEO que cubren SEO técnico, optimización on-page, datos estructurados, Core Web Vitals y estrategia de contenidos. Se activa al solicitar visibilidad en búsquedas, corrección de errores SEO, mapas de sitio (sitemaps), configuración de robots.txt o mapeo de palabras clave. |
| [**seo-audit**](./seo-audit/SKILL.md) | Se activa cuando el usuario quiere auditar, analizar o diagnosticar el estado del SEO de su sitio. Aplica si el usuario reporta pérdidas de tráfico, caídas de ranking, problemas de indexación, errores de velocidad de carga o si se vio afectado por una actualización de algoritmo de Google. Incluso ante peticiones vagas como "mi SEO va mal", se inicia un diagnóstico completo con esta skill. Para crear páginas en lote, ver `programmatic-seo`. Para datos estructurados, ver `schema`. Para búsquedas de IA, ver `ai-seo`. |
| [**site-architecture**](./site-architecture/SKILL.md) | Se activa al planificar, esquematizar o reestructurar la jerarquía de páginas de un sitio, su sistema de navegación, estructura de URLs o enlazado interno (Arquitectura de Información). Sirve para decidir qué páginas se necesitan y cómo se conectan entre sí. Nota: No es para sitemaps XML técnicos (ver `seo-audit`). Para datos estructurados, ver `schema`. |

### 🎯 Marketing, Crecimiento (Growth) y Conversión

| :--- | :--- |
| [**ab-testing**](./ab-testing/SKILL.md) | Se activa al planificar, diseñar o implementar pruebas A/B, experimentos de conversión o estructurar un programa de experimentación sistemático (ej. puntuación ICE, backlog de experimentos). Cubre la comparación de variantes de copy o diseño, cálculo de significancia estadística y tiempos de prueba. Para la medición técnica de eventos, ver `analytics`. Para optimización de conversión a nivel de página, ver `cro`. |
| [**ad-creative**](./ad-creative/SKILL.md) | Se activa al generar, iterar o escalar creatividades publicitarias (titulares, descripciones, copys principales) para cualquier plataforma de anuncios de pago (Google Ads, Meta, LinkedIn). Se usa para crear variaciones de anuncios de texto adaptables (RSA) y optimizar el rendimiento creativo. Para estrategia y segmentación de campañas, ver `ads`. Para textos de landing pages, ver `copywriting`. |
| [**ads**](./ads/SKILL.md) | Se activa al buscar ayuda estratégica para campañas de publicidad de pago (PPC, campañas en Meta/Google/LinkedIn, presupuestos, retorno de inversión en anuncios o ROAS, segmentación de audiencias y retargeting). Para la redacción masiva de anuncios, ver `ad-creative`. Para optimización de conversión de las páginas de destino, ver `cro`. |
| [**analytics**](./analytics/SKILL.md) | Se activa al configurar, auditar o mejorar la medición y el análisis de datos en la web (Google Analytics 4, Tag Manager, planes de seguimiento de eventos, parámetros UTM, atribución, Mixpanel o Segment). Útil para responder a preguntas sobre cómo medir los resultados y si las conversiones están registrándose bien. Para la medición de pruebas A/B, ver `ab-testing`. |
| [**article-writing**](./article-writing/SKILL.md) | Redacta artículos, guías, publicaciones de blog, tutoriales o boletines (newsletters) con una voz de marca consistente y distintiva. Se activa cuando se requiere contenido escrito de formato largo (más de un párrafo) donde la credibilidad, estructura y consistencia del tono son clave. |
| [**brand-discovery**](./brand-discovery/SKILL.md) | Se activa cuando una marca necesita definir y estructurar su identidad a través de un proceso de entrevistas guiadas. Cubre propósito, posicionamiento, público objetivo, personalidad de marca, voz, narrativa y alineación del fundador. Produce un libro de marca maestro (`90_SYNTHESIS.md`) y permite guardar el estado de la sesión para retomarla en cualquier momento. |
| [**brand-voice**](./brand-voice/SKILL.md) | Crea un perfil de estilo de redacción basado en fuentes reales (ensayos, notas de lanzamiento, posts, documentación o textos de la web) para reutilizarlo en la creación de contenidos, redes sociales y correos salientes. Se activa cuando el usuario busca mantener un tono de voz coherente y evitar los clichés de redacción típicos de las IA genéricas. |
| [**churn-prevention**](./churn-prevention/SKILL.md) | Se activa cuando el usuario quiere reducir la tasa de cancelación (churn), crear flujos de baja con ofertas de retención, recuperar pagos fallidos (dunning), encuestas de salida u otras estrategias de retención. Para secuencias de correo de recuperación tras cancelar, ver `emails`. Para pantallas de pago o actualización en la app, ver `paywalls`. |
| [**co-marketing**](./co-marketing/SKILL.md) | Se activa para buscar socios de co-marketing, planificar campañas conjuntas o idear colaboraciones entre marcas y promociones cruzadas. Para programas de referidos, ver `referrals`. Para alianzas ligadas a un lanzamiento, ver `launch`. |
| [**cold-email**](./cold-email/SKILL.md) | Escribe correos fríos B2B y secuencias de seguimiento efectivas. Se activa para campañas de prospección saliente, correos de SDR, redacción de líneas de asunto persuasivas, llamadas a la acción (CTAs) y personalización del contacto inicial. Para secuencias de correo de nutrición o ciclo de vida del cliente (leads ya tibios), ver `emails`. |
| [**community-marketing**](./community-marketing/SKILL.md) | Diseña y potencia comunidades online (Discord, Slack, subreddits) para impulsar el crecimiento orgánico del producto y fidelizar clientes (crecimiento liderado por la comunidad, programas de embajadores). Se activa ante frases sobre crear comunidades, estrategias de foro y engagement posregistro. |
| [**competitive-platform-analysis**](./competitive-platform-analysis/SKILL.md) | Se activa para realizar el análisis inicial del panorama competitivo: identificar, categorizar y filtrar con puntuaciones un conjunto de competidores antes de iniciar la comparación formal (benchmarking). Decide quién califica como competidor, su relevancia y qué fuentes de datos analizar. Es el paso previo a `benchmark-methodology`. |

Para contenidos puramente de redes sociales, ver `social`. |
| [**copy-editing**](./copy-editing/SKILL.md) | Se activa cuando el usuario quiere editar, revisar, pulir o corregir textos de marketing ya existentes o actualizar contenidos obsoletos (sin redactar de cero). Cubre la corrección de textos redundantes, aclaración del mensaje o auditorías de redacción. Para escribir textos nuevos, ver `copywriting`. |

Diseñado para persuadir al visitante a realizar una acción. Para redacción de correos, ver `emails`. Para editar textos existentes, ver `copy-editing`. Para pulir la oferta subyacente (garantías, bonos), ver `offers`. |

Aplica ante problemas como páginas que no convierten, abandono de formularios, o cuando el usuario comparte un enlace para recibir retroalimentación del embudo de conversión. Para flujos de registro, ver `signup`. Para activación posregistro, ver `onboarding`. Para ventanas emergentes, ver `popups`. |
| [**crosspost**](./crosspost/SKILL.md) | Distribución de contenido multiplataforma adaptando el formato específicamente para X, LinkedIn, Threads y Bluesky sin publicar copias idénticas. Se activa al solicitar la redacción y distribución simultánea de posts sociales. |

| [**deep-research**](./deep-research/SKILL.md) | Búsqueda profunda en múltiples fuentes web usando Firecrawl y Exa MCP. Realiza búsquedas sistemáticas, sintetiza hallazgos y entrega reportes citados y estructurados con atribución de fuentes. Se activa al solicitar investigación exhaustiva sobre cualquier tema que requiera evidencias y fuentes comprobables. |
| [**directory-submissions**](./directory-submissions/SKILL.md) | Se activa cuando el usuario quiere registrar su producto en directorios de startups, SaaS, IA, MCP o portales de reseñas para ganar visibilidad y enlaces entrantes (backlinks) de autoridad. | [**email-ops**](./email-ops/SKILL.md) | Gestión de bandeja de entrada basada en evidencias, redacción, verificación de envíos y flujo de seguimiento seguro para correos. Se activa al organizar correo, redactar o enviar emails reales y validar su recepción correcta. |
| [**emails**](./emails/SKILL.md) | Se activa al crear y optimizar secuencias de correo electrónico automatizadas, campañas de goteo (drip campaigns), correos de bienvenida, secuencias de nutrición (nurture) o correos basados en el comportamiento del usuario. | [**free-tools**](./free-tools/SKILL.md) | Se activa para evaluar y planificar herramientas gratuitas como estrategia de captación (ingeniería como marketing). Cubre compresión de imágenes, formatos WebP y generación de imágenes Open Graph (OG). Para creatividades publicitarias pagadas, ver `ad-creative`. Para producción de video, ver `video`. |
| [**launch**](./launch/SKILL.md) | Se activa al planificar el lanzamiento de un producto, la presentación de una funcionalidad o la estrategia de salida al mercado (GTM). Útil para listas de control de lanzamiento, captación de lista de espera (waitlist) y campañas de anuncio público. |
| [**lead-magnets**](./lead-magnets/SKILL.md) | Se activa al estructurar y optimizar imanes de leads (lead magnets) para captar correos (ebooks, guías rápidas, plantillas descargables, Notion templates o recursos en PDF). Para herramientas gratuitas interactivas, ver `free-tools`. |
| [**market-research**](./market-research/SKILL.md) | Realiza investigación de mercado, análisis competitivo, debida diligencia de inversores e inteligencia de la industria con citación de fuentes y resúmenes ejecutivos listos para la toma de decisiones. Se activa al requerir dimensionamiento de mercado, perfiles de inversores, mapeo tecnológico o análisis competitivo comercial. |
| [**marketing-campaign**](./marketing-campaign/SKILL.md) ⚡ | Planificación y ejecución de campañas de marketing multicanal integrales. Abarca investigación de audiencias, posicionamiento, definición de ángulos, copies de landing pages, secuencias de correo, posts sociales, copys de anuncios, guiones de video y calendarios de contenido. Se activa al diseñar una campaña completa, no para un activo suelto. |
| [**marketing-ideas**](./marketing-ideas/SKILL.md) | Se activa cuando el usuario está atascado y necesita lluvias de ideas de marketing, tácticas de crecimiento orgánico o formas creativas de promocionar un software o SaaS. Sirve de punto de partida antes de ir a canales concretos. |
| [**marketing-plan**](./marketing-plan/SKILL.md) | Se activa al requerir un plan de marketing estratégico completo adaptado al presupuesto, equipo y fase de financiación de la empresa. Genera una auditoría del estado actual y estructura el plan bajo el modelo AARRR. |
| [**marketing-psychology**](./marketing-psychology/SKILL.md) | Se activa al aplicar principios de psicología del comportamiento humano y sesgos cognitivos al marketing (prueba social, anclaje de precios, escasez, aversión a la pérdida y encuadre). Para optimización de páginas, ver `cro`. Para precios, ver `pricing`. |

| [**popups**](./popups/SKILL.md) | Se activa al diseñar o evaluar elementos emergentes como ventanas popups de salida (exit intent), modales de captación de correo, banners informativos superiores o barras flotantes de conversión. |
